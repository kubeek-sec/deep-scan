# deepscan-mcp

MCP server exposing the Deep Scan scanner library to agents/IDEs.

Tools: `static_scan`, `dynamic_scan`, `scan_family`, `scan_with`,
`list_scanners`, `tool_status`, `install_tool`, and the code-graph query tools
`list_graph_questions` / `query_graph` (precise AppSec questions about a project:
unsanitized sources, critical functions, endpoints→sink/taint, attack paths,
blast radius, …).

See the repository root README for details.
